# クラウド用語ドリル

AWS 認定クラウドプラクティショナー（CLF-C02）の用語とサービスを覚える静的サイトです。`python build.py` を実行すると `docs/` に全ページが書き出され、そのまま GitHub Pages で公開できます。サーバもデータベースも要りません。

姉妹サイト「ITパスポート用語ドリル」（リポジトリ `yuki-fe/ip-drill`）の仕組みをもとに作っています。

- 公開URL（予定）: https://cloud.yogo-drill.com/

## フォルダの中身

| パス | 内容 | 編集するか |
|---|---|---|
| `config.json` | サイト名・公開URL・姉妹サイト・運営者・アクセス解析・広告の設定 | する |
| `data/make_terms.py` | 用語の元データ。実行すると `data/terms.json` を作る | する |
| `data/terms.json` | 用語データ（`make_terms.py` が作る） | しない |
| `build.py` | ページを生成するスクリプト。分野（`FIELDS`）、ミニテストの問題数（`TEST_COUNTS`）、運営者情報・プライバシーポリシーの文面もここにある | 文面を変えるとき |
| `static/assets/` | CSS と JavaScript。`app.js` ホームの単語帳、`drill.js` ミニテストと略語クイズ、`term.js` 用語ページの確認問題 | 見た目や機能を変えるとき |
| `docs/` | 生成されたサイト。**直接編集しない**（ビルドのたびに作り直される） | しない |

## 普段の作業

```powershell
cd "C:\Users\admin\Desktop\cloud-drill"
python data/make_terms.py             # 用語を直したとき
python build.py                       # docs/ を作り直す
python -m http.server 8000 -d docs    # http://localhost:8000 で確認（Ctrl+C で終了）
```

## 用語を追加・修正する

`data/make_terms.py` の `TERMS` に、`(分野, 小分類, 用語, 正式名, 説明)` の形で書きます。

- 分野は `C`（クラウドの概念）/ `S`（セキュリティとコンプライアンス）/ `T`（クラウドのテクノロジーとサービス）/ `B`（請求・料金・サポート）
- id は並び順で付く。**公開後は、新しい用語をリストの最後に足す**（途中に足したり消したりすると、ページの URL `terms/0001.html` がずれる）
- 正式名を書くと、略語クイズと略語の早見表に入る
- 「Amazon EC2」「AWS Lambda」は、「EC2」「Lambda」と入力しても正解になる
- 出題範囲は AWS の試験ガイド（CLF-C02）に合わせる。サービスの名前・機能・料金は変わるので、足すときは AWS のドキュメントで確かめる。料金の金額など、変わりやすい数字は書かない

## 学習の記録

進み具合はブラウザの localStorage に保存します。FE・ITパスポートのサイトと同じ `yuki-fe.github.io` の上で動くので、保存の名前は `cloud-drill-` で始めています。

## 商標について

AWS の商標の決まりで、サイトの名前やドメインに「AWS」を入れることはできません（URL の後ろの部分は可）。サイト名は「クラウド用語ドリル」とし、「AWS 認定クラウドプラクティショナーの用語」と事実として文字で書くだけにしています。AWS のロゴは使いません。全ページの下に、商標と「関係がない」ことの注意書きを出しています。
