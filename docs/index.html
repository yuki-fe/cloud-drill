クラウド用語ドリルAWS 認定クラウドプラクティショナー（CLF-C02）の用語を無料で覚える単語帳

AWS 認定クラウドプラクティショナー（CLF-C02）の試験ガイドに出てくる用語とサービスを、248語収録しています。クラウドを初めて学ぶ人にも分かるように、やさしい言葉で説明しています。登録は不要で、スマホでもパソコンでも無料で使えます。

学び方

カード
意味を読んで用語を思い出し、裏返して確かめます。「用語 → 意味」の向きにも切り替えられます。
4択クイズ
4つの選択肢から答えを選びます。同じ分野の、まぎらわしい用語がひっかけとして並びます。
書いて答える
説明を読んで、用語を自分で入力します。「Amazon EC2」は「EC2」のように、Amazon・AWS を省いても正解になります。
復習
「まだ」を押した用語や、クイズで間違えた用語だけを集めて、学習し直せます。
ミニテスト
試験の4つの分野から、試験ガイドの配点に近い割合で20問を出します。分野ごとの正答率がわかります。
略語クイズ
EC2・IAM・VPC など、アルファベットの略語の正式名を覚えます。

試験の分野

試験は65問（採点される50問と、採点されない15問）で、選択肢から1つ、または2つ以上を選ぶ形です。結果は100〜1,000点で、700点以上で合格です。分野ごとの合格点はなく、全体の点数で決まります。配点は、クラウドの概念が24%、セキュリティとコンプライアンスが30%、クラウドのテクノロジーとサービスが34%、請求・料金・サポートが12%です。

  • クラウドの概念36語
  • セキュリティとコンプライアンス49語
  • テクノロジーとサービス127語
  • 請求・料金・サポート36語

すべての用語は用語一覧から、1語ずつ解説ページで読めます。
