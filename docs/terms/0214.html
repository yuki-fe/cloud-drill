リザーブドインスタンス（RI）

正式名Reserved Instance

1年か3年の利用を約束することで、オンデマンドより大きく割引される EC2 などの買い方。ずっと動かしておくシステムに向く。

同じ分野の用語

  • オンデマンドインスタンス

    前もって約束せず、使った時間の分だけ払う EC2 の買い方。急な仕事や、短い期間の利用に向く。

  • リザーブドインスタンスの柔軟性

    スタンダードとコンバーティブルがあり、コンバーティブルは期間の途中でインスタンスのタイプを変えられる。リージョン単位のリザーブドインスタンスは、同じファミリーの別の大きさにも割引が当たる。

  • スポットインスタンス

    AWS の余っている EC2 を、大きな割引で使える買い方。AWS が必要になると中断されることがあるので、止まってもよい処理に向く。

  • Savings Plans

    1年か3年、1時間あたりの利用額を約束することで割引される料金のプラン。インスタンスのタイプを変えても当てはまり、Lambda や Fargate にも使える種類がある。

  • Dedicated Instances

    ほかの利用者と共有しない、専用のハードウェアの上で動く EC2 のインスタンス。ハードウェア専有インスタンスとも呼ぶ。

  • Dedicated Hosts

    物理サーバー1台を、まるごと自分専用にする仕組み。サーバー単位のソフトウェアのライセンス（BYOL）を使いたいときに向く。
