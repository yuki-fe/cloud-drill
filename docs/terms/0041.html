セキュリティとコンプライアンス・責任共有モデル

サービスによる責任の違い

利用者の責任の範囲は、使うサービスで変わること。EC2 では OS の更新も利用者の責任だが、RDS や Lambda では OS の管理を AWS が受け持つ。

同じ分野の用語

  • 共通の統制

    AWS と利用者の両方が、それぞれの範囲で行う管理。パッチの管理・設定の管理・セキュリティの教育など。

  • クラウドにおけるセキュリティ

    責任共有モデルで利用者が受け持つ範囲。データ、アクセスの設定、ファイアウォールの設定、暗号化、EC2 なら OS の更新など。

  • クラウドのセキュリティ

    責任共有モデルで AWS が受け持つ範囲。データセンターの建物・機器・ネットワーク・仮想化の仕組みなど、サービスを動かす土台を守る。

  • 責任共有モデル

    セキュリティの責任を AWS と利用者で分ける考え方。AWS は「クラウドのセキュリティ」、利用者は「クラウドにおけるセキュリティ」を受け持つ。
