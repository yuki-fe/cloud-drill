AWS Secrets Manager

データベースのパスワードや API キーなどの秘密の情報を安全に保管し、定期的に自動で切り替える（ローテーション）サービス。

同じ分野の用語

  • AWS Directory Service

    Microsoft Active Directory を、AWS の中で使えるようにするサービス。

  • AWS RAM

    サブネットなどの資源を、ほかの AWS アカウントと共有するサービス。

  • Amazon Cognito

    Web やスマホのアプリに、会員登録とログインの機能を付けるサービス。

  • SCP（サービスコントロールポリシー）

    AWS Organizations で、メンバーのアカウントが使える権限の上限を決めるポリシー。

  • クロスアカウント IAM ロール

    別の AWS アカウントの利用者が、ロールを引き受けて一時的に権限を使えるようにする仕組み。

  • ID フェデレーション

    会社の ID などの外部の ID を使って、AWS にログインできるようにする仕組み。AWS の中に別のユーザーを作らなくてよい。
