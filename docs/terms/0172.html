同じ分野の用語

  • AWS Backup

    多くの AWS のサービスのバックアップを、1か所でまとめて設定・管理するサービス。

  • AWS Storage Gateway

    社内のシステムと AWS のストレージをつなぎ、よく使うデータは手元に置き（キャッシュ）ながら、AWS に保存するサービス。ハイブリッドで使う。

  • Amazon FSx

    Windows File Server や Lustre など、よく使われるファイルシステムを、AWS が管理して提供するサービス。

  • Amazon EFS

    複数の EC2 から同時に使える、容量が自動で増えるファイルストレージ。

  • EBS スナップショット

    EBS のある時点の状態を保存したバックアップ。

  • インスタンスストア

    EC2 の機器に直接ついている一時的なディスク。速いが、インスタンスを止めるとデータが消える。
