AWS Shield

DDoS 攻撃からシステムを守るサービス。Standard は追加料金なしで自動で使え、Advanced は有料で、より高度な保護と専門チームの支援がある。

同じ分野の用語

  • AWS WAF

    Web アプリへの攻撃（SQL インジェクションなど）を、ルールで見分けて止めるファイアウォール。CloudFront などと組み合わせて使う。

  • DDoS 攻撃

    たくさんのコンピュータから大量の通信を送りつけて、サービスを使えなくする攻撃。

  • AWS Firewall Manager

    複数のアカウントの WAF や Shield などのルールを、まとめて設定・管理するサービス。

  • Amazon GuardDuty

    ログを機械学習などで分析し、不正なアクセスやあやしい動きを見つけて知らせるサービス。

  • Amazon Inspector

    EC2・コンテナのイメージ・Lambda の関数に、ソフトウェアの脆弱性や意図しないネットワークへの公開がないかを、自動で調べるサービス。

  • Amazon Macie

    S3 に保存されたデータの中から、個人情報などの大事なデータを機械学習で見つけて知らせるサービス。
