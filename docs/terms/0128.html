テクノロジーとサービス・データベース

Amazon DocumentDB

JSON のようなドキュメントの形のデータを扱うデータベース。MongoDB と互換がある。

同じ分野の用語

  • Amazon Neptune

    人と人のつながりのような「関係」のデータを扱う、グラフデータベースのサービス。

  • リレーショナルデータベース

    表（テーブル）の形でデータを持ち、SQL で操作するデータベース。

  • Amazon ElastiCache

    データをメモリに置いて、とても速く読み出せるようにするサービス（キャッシュ）。Redis や Memcached と互換がある。

  • NoSQL データベース

    表の形にとらわれず、キーと値やドキュメントなどの形でデータを持つデータベース。大量のデータを速く扱うのに向く。

  • Amazon DynamoDB

    キーと値で読み書きする NoSQL のデータベース。サーバーの管理がいらず、大量のアクセスでも速く応える。

  • マネージドサービス

    サーバーの準備・更新・バックアップなどの手間を、AWS が受け持つサービス。例えば RDS は、EC2 に自分でデータベースを入れるより管理が楽になる。
