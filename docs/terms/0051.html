セキュリティとコンプライアンス・アクセス管理

最小権限の原則

仕事に必要な、最小限の権限だけを与える考え方。間違いや乗っ取りがあったときの被害を小さくできる。

カードで練習する 書いて答える問題に挑戦

同じ分野の用語

  • カスタマー管理ポリシー

    利用者が自分で書いて管理する IAM ポリシー。必要な権限だけに細かく絞れる。

  • MFA

    多要素認証。パスワードに加えて、スマホのアプリなどが出す1回だけの番号でも本人を確かめる方法。ルートユーザーには必ず設定する。

  • AWS 管理ポリシー

    AWS があらかじめ用意している IAM ポリシー。よくある使い方の権限を、すぐに付けられる。

  • アクセスキー

    プログラムや CLI から AWS を使うための、アクセスキー ID とシークレットアクセスキーの組。人に見せたり、コードに書いたりしない。

  • IAM ポリシー

    「何に対して、何をしてよいか（してはいけないか）」を JSON で書いた権限の決まり。ユーザー・グループ・ロールに付ける。

  • パスワードポリシー

    IAM ユーザーのパスワードの長さ・使う文字の種類・有効期限などの決まり。
