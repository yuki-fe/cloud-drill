同じ分野の用語

  • Amazon Route 53

    AWS の DNS のサービス。ドメイン名の登録、名前から IP アドレスへの変換、通信の振り分けを行う。

  • AWS Direct Connect

    自社のデータセンターと AWS を、インターネットを通らない専用の線でつなぐサービス。通信が安定していて速い。

  • ネットワーク ACL

    サブネットの単位で付けるファイアウォール。許可と拒否の両方のルールを書け、行きと戻りの通信を別々に決める（ステートレス）。

  • AWS VPN

    インターネットを通して、暗号化した通信で安全に AWS とつなぐサービス。Site-to-Site VPN と Client VPN がある。

  • セキュリティグループ

    EC2 などに付ける仮想のファイアウォール。許可する通信だけを決める。行きの通信を許すと、戻りの通信も自動で許される（ステートフル）。

  • AWS Site-to-Site VPN

    会社のネットワークと VPC を、インターネットを通る暗号化した通信でつなぐサービス。
