S3 ライフサイクルポリシー

日数などの決まりに合わせて、S3 のデータを安いクラスへ自動で移したり、消したりする設定。

同じ分野の用語

  • S3 Glacier Deep Archive

    S3 でいちばん安いストレージクラス。取り出しには時間がかかる。何年も保存しておく記録向け。

  • Amazon EBS

    EC2 につないで使うブロックストレージ（ディスク）。EC2 を止めてもデータは残る。スナップショットでバックアップできる。

  • Amazon S3 Glacier

    長く保存しておく（アーカイブ）データ向けの、とても安い S3 のストレージクラスの仲間。Instant Retrieval・Flexible Retrieval・Deep Archive があり、取り出しの速さと料金が違う。

  • インスタンスストア

    EC2 の機器に直接ついている一時的なディスク。速いが、インスタンスを止めるとデータが消える。

  • S3 One Zone-IA

    1つのアベイラビリティーゾーンだけに保存する、あまり使わないデータ向けのクラス。安いが、その AZ が壊れると失われることがあるので、作り直せるデータに使う。

  • EBS スナップショット

    EBS のある時点の状態を保存したバックアップ。

確認問題
