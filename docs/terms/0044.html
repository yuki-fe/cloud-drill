同じ分野の用語

  • ルートユーザー

    AWS アカウントを作ったときのメールアドレスでログインする、すべての権限を持つユーザー。ふだんの作業には使わず、MFA を設定して守る。

  • IAM ユーザー

    AWS を使う人やアプリごとに作る ID。パスワードやアクセスキーを持てる。

  • AWS IAM

    だれが、どの AWS のサービスや資源を使えるかを管理するサービス。ユーザー・グループ・ロール・ポリシーを使う。追加料金はかからない。

  • IAM グループ

    IAM ユーザーをまとめたもの。グループに権限を付けると、入っている全員に同じ権限が付く。

  • IAM ロール

    一時的に権限を借りるための ID。EC2 などのサービスや、別のアカウントの利用者に、決まった権限を一時的に渡すときに使う。

  • IAM ポリシー

    「何に対して、何をしてよいか（してはいけないか）」を JSON で書いた権限の決まり。ユーザー・グループ・ロールに付ける。
