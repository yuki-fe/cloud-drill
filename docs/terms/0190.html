テクノロジーとサービス・そのほかのサービス

Amazon SNS

正式名Amazon Simple Notification Service

メッセージを、メール・SMS・アプリなど多くの受け取り先へ一斉に送る（通知する）サービス。

カードで練習する 略語クイズに挑戦

同じ分野の用語

  • Amazon EventBridge

    アプリや AWS のサービスで起きた出来事（イベント）を受けて、決めた処理につなぐサービス。決まった時刻に処理を動かすこともできる。

  • Amazon SQS

    メッセージを順番待ちの列（キュー）にためて、アプリどうしを切り離してやり取りさせるサービス。

  • AWS Step Functions

    複数のサービスの処理の流れ（ワークフロー）を、図のように組み立てて自動で動かすサービス。

  • Amazon Connect

    クラウドで使える、コールセンター（コンタクトセンター）のサービス。

  • Amazon SES

    お知らせや案内のメールを、大量に送るサービス。

  • AWS CodeBuild

    プログラムのコードをビルドして、テストまで自動で行うサービス。

確認問題

次の説明に当てはまる用語はどれか。
