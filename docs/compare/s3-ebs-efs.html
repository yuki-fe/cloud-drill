S3とEBSとEFSの違い

S3はファイルを名前を付けて置いておく「倉庫」（オブジェクトストレージ）、EBSは1台のEC2につなぐ「ディスク」（ブロックストレージ）、EFSは複数のEC2から同時に使える「共有フォルダ」（ファイルストレージ）です。

表で比べる

観点Amazon S3Amazon EBSAmazon EFS
ストレージの種類オブジェクトストレージブロックストレージファイルストレージ
たとえインターネットの上の倉庫パソコンにつないだディスクみんなで使う共有フォルダ
使い方Web やプログラムから、オブジェクト（ファイル）を出し入れするEC2 につないで、OS やアプリのディスクとして使う複数の EC2 にマウントして、同時に読み書きする
つなぐ相手EC2 につながなくても使える基本は1台の EC2（同じアベイラビリティーゾーンのもの）複数の EC2 から同時に使える
容量上限を気にせず置けるボリュームの大きさを決めて作る使った分だけ自動で増える
向いている用途画像・動画・バックアップ・ログ・静的な Web サイトEC2 の OS、データベースのディスク複数のサーバーで共有するファイル

見分けるポイント

  • 「オブジェクト」「バケット」「容量の上限を気にせず」「静的な Web サイト」が出てきたら S3
  • 「EC2 のディスク」「ブロック」「スナップショット」が出てきたら EBS
  • 「複数の EC2 から同時に」「共有」「ファイルシステム」が出てきたら EFS
  • EBS は EC2 を止めてもデータが残る。止めると消えるのはインスタンスストア

試験での出され方

「複数の EC2 インスタンスから同時にアクセスできるストレージはどれか」「大量の画像を低コストで長く保存したい」のように、場面から合うストレージを選ぶ問題がよく出ます。まず「オブジェクト・ブロック・ファイル」のどれかを考えると見分けやすくなります。

それぞれの用語

  • Amazon S3

    容量の上限なくファイルを保存できる、オブジェクトストレージのサービス。データを複数の場所に保存していて、耐久性がとても高い。

  • Amazon EBS

    EC2 につないで使うブロックストレージ（ディスク）。EC2 を止めてもデータは残る。スナップショットでバックアップできる。

  • Amazon EFS

    複数の EC2 から同時に使える、容量が自動で増えるファイルストレージ。
