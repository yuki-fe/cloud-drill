Amazon SNS と Amazon SQS の違い

SNS はメッセージを多くの受け取り先へ一斉に送る（通知する）サービス、SQS はメッセージを列（キュー）にためておき、受け取る側が自分の都合で取り出すサービスです。

表で比べる

観点Amazon SNSAmazon SQS
しくみ送られたメッセージを、登録している受け取り先へ一斉に配るメッセージをキューにためておく
受け取り方SNS のほうから届ける（プッシュ）受け取る側が取りに行く（ポーリング）
受け取る数1つのメッセージを、たくさんの受け取り先へ1つのメッセージは、ふつう1つの処理が受け取る
受け取り先メール・SMS・アプリ・Lambda・SQS などアプリ（EC2 や Lambda など）
たとえ校内放送銀行の番号札の順番待ち

見分けるポイント

  • 「通知」「一斉に送る」「メールや SMS」「パブリッシュ／サブスクライブ」なら SNS
  • 「キュー」「メッセージをためる」「アプリどうしを切り離す（疎結合）」なら SQS
  • 受け取る側が止まっていても、SQS ならメッセージはキューに残って待てる
  • SNS で一斉に送り、それぞれを SQS で受けてためる組み合わせもある

試験での出され方

「アプリケーションの部品どうしを疎結合にしたい」なら SQS、「システムの異常を担当者にメールで通知したい」なら SNS のように、目的から選ぶ問題がよく出ます。

それぞれの用語

  • Amazon SNS

    メッセージを、メール・SMS・アプリなど多くの受け取り先へ一斉に送る（通知する）サービス。

  • Amazon SQS

    メッセージを順番待ちの列（キュー）にためて、アプリどうしを切り離してやり取りさせるサービス。
