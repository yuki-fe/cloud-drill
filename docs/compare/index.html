似た用語の違いAWS 認定クラウドプラクティショナーでまぎらわしい用語 15組

試験では、役割の似たサービスや用語の中から、場面に合うものを選ぶ問題がよく出ます。2つ（3つ以上）の用語を表で並べて、どこが違うかを確かめましょう。

  • S3とEBSとEFSの違い

    S3はファイルを名前を付けて置いておく「倉庫」（オブジェクトストレージ）、EBSは1台のEC2につなぐ「ディスク」（ブロックストレージ）、EFSは複数のEC2から同時に使える「共有フォルダ」（ファイルストレージ）です。

  • セキュリティグループとネットワーク ACL の違い

    どちらも VPC の中で通信を通すか決めるファイアウォールです。セキュリティグループは EC2 などの1台ごと（インスタンス単位）、ネットワーク ACL はサブネットごとに付けます。

  • リージョンとアベイラビリティーゾーンとエッジロケーションの違い

    リージョンは世界の地域、アベイラビリティーゾーン（AZ）はリージョンの中にある独立したデータセンターの集まり、エッジロケーションは利用者の近くでデータを速く届けるための拠点です。

  • オンデマンドとリザーブドインスタンスとスポットインスタンスと Savings Plans の違い

    EC2 の買い方の違いです。約束なしで使った分だけ払うのがオンデマンド、1年か3年の約束で安くするのがリザーブドインスタンスと Savings Plans、余っている EC2 を中断ありで安く使うのがスポットインスタンスです。

  • CloudTrail と CloudWatch と Config の違い

    CloudTrail は「だれが何をしたか」の操作の記録、CloudWatch は「今どんな状態か」の監視とアラーム、Config は「資源の設定がどうなっているか・どう変わったか」の記録とルールの確認です。

  • IAM ユーザーと IAM グループと IAM ロールの違い

    IAM ユーザーは人やアプリごとの ID、IAM グループはユーザーをまとめて同じ権限を付けるための入れ物、IAM ロールは一時的に権限を借りるための ID です。権限そのものは IAM ポリシーで決めます。

  • GuardDuty と Inspector と Macie と Detective の違い

    GuardDuty は不正なアクセスやあやしい動きを見つけ、Inspector はソフトウェアの脆弱性を調べ、Macie は S3 の中の個人情報などを見つけ、Detective は見つかった問題の原因を調べるのを助けます。

  • AWS Shield と AWS WAF の違い

    AWS Shield は大量の通信でサービスを止める DDoS 攻撃から守るサービス、AWS WAF は SQL インジェクションなど Web アプリをねらう攻撃を、決めたルールで止めるファイアウォールです。

  • AWS KMS と AWS CloudHSM の違い

    どちらも暗号化の鍵を管理するサービスです。KMS は AWS が管理する仕組みで手軽に使え、多くの AWS のサービスとつながります。CloudHSM は自分専用のハードウェア（HSM）で、鍵を自分だけで管理します。

  • RDS と Aurora と DynamoDB の違い

    RDS は MySQL などのリレーショナルデータベースを AWS が管理してくれるサービス、Aurora は AWS がクラウド向けに作った高性能なリレーショナルデータベース、DynamoDB はキーと値で読み書きする NoSQL のデータベースです。

  • AWS Direct Connect と AWS VPN の違い

    どちらも会社のネットワークと AWS をつなぐサービスです。Direct Connect はインターネットを通らない専用の線、VPN はインターネットを通る暗号化した通信でつなぎます。

  • AWS Budgets と Cost Explorer と Pricing Calculator の違い

    Pricing Calculator は使う前に料金を見積もる道具、Cost Explorer はこれまでの料金をグラフで分析する道具、AWS Budgets は予算を決めて超えそうなときに知らせるサービスです。

  • Amazon SNS と Amazon SQS の違い

    SNS はメッセージを多くの受け取り先へ一斉に送る（通知する）サービス、SQS はメッセージを列（キュー）にためておき、受け取る側が自分の都合で取り出すサービスです。

  • リホストとリプラットフォームとリファクタリングの違い

    クラウドへの移し方の違いです。リホストはそのまま移す、リプラットフォームは一部だけクラウド向けに変えて移す、リファクタリングはクラウドの機能を生かすように大きく作り直して移します。

  • S3 のストレージクラスの違い（Standard・Standard-IA・One Zone-IA・Glacier Deep Archive）

    S3 のストレージクラスは、どれくらいよく使うか、どれくらい速く取り出したいかで選びます。よく使うなら Standard、あまり使わないなら IA（Infrequent Access）、何年も保管するだけなら Glacier Deep Archive です。
