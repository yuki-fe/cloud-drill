S3 のストレージクラスの違い（Standard・Standard-IA・One Zone-IA・Glacier Deep Archive）

S3 のストレージクラスは、どれくらいよく使うか、どれくらい速く取り出したいかで選びます。よく使うなら Standard、あまり使わないなら IA（Infrequent Access）、何年も保管するだけなら Glacier Deep Archive です。

表で比べる

向いているデータよく見る画像・Web サイトのファイルバックアップなど、たまにすぐ必要になるデータなくなっても作り直せるデータ法律などで何年も残しておく記録

見分けるポイント

  • 「使われ方がわからない」「自動でクラスを移す」なら S3 Intelligent-Tiering
  • 「あまり使わないが、必要なときはすぐ」なら Standard-IA
  • 「作り直せるデータ」「1つの AZ でよい」なら One Zone-IA
  • 「長期間のアーカイブ」「いちばん安い」「取り出しに時間がかかってもよい」なら Glacier Deep Archive
  • 日数に合わせてクラスを自動で移すのは、S3 ライフサイクルポリシー

試験での出され方

「何年も保管する必要があり、ほとんど取り出さないデータを最も安く保存するには」なら Glacier Deep Archive、「アクセスの頻度が予測できない」なら Intelligent-Tiering のように、使い方から選ぶ問題がよく出ます。

それぞれの用語

  • S3 Standard

    よく使うデータ向けの、標準の S3 のストレージクラス。

  • S3 Standard-IA

    あまり使わないが、必要なときはすぐ取り出したいデータ向けの S3 のストレージクラス。保存は安いが、取り出すときに料金がかかる。

  • S3 One Zone-IA

    1つのアベイラビリティーゾーンだけに保存する、あまり使わないデータ向けのクラス。安いが、その AZ が壊れると失われることがあるので、作り直せるデータに使う。

  • S3 Glacier Deep Archive

    S3 でいちばん安いストレージクラス。取り出しには時間がかかる。何年も保存しておく記録向け。
