AWS Direct Connect と AWS VPN の違い

どちらも会社のネットワークと AWS をつなぐサービスです。Direct Connect はインターネットを通らない専用の線、VPN はインターネットを通る暗号化した通信でつなぎます。

表で比べる

観点AWS Direct ConnectAWS VPN（Site-to-Site VPN）
通る道インターネットを通らない専用の線インターネット（暗号化した通信）
速さ・安定速く、安定しているインターネットの混み具合に左右される
用意にかかる時間線を引くので、時間がかかるすぐに用意できる
向いている場面大量のデータをいつも安定してやり取りしたいすぐに安全につなぎたい、Direct Connect の予備にしたい

見分けるポイント

  • 「専用の接続」「インターネットを経由しない」「安定した帯域」なら Direct Connect
  • 「インターネット経由で暗号化」「すぐに設定できる」なら VPN
  • 社員の PC 1台ずつからつなぐなら Client VPN、会社のネットワークごとつなぐなら Site-to-Site VPN
  • Direct Connect の予備（バックアップ）の経路として VPN を使う組み合わせもある

試験での出され方

「オンプレミスと AWS を、インターネットを経由せずにつなぎたい」なら Direct Connect、「短い時間で、インターネット経由の暗号化した接続を作りたい」なら Site-to-Site VPN を選ぶ問題がよく出ます。

それぞれの用語

  • AWS Direct Connect

    自社のデータセンターと AWS を、インターネットを通らない専用の線でつなぐサービス。通信が安定していて速い。

  • AWS VPN

    インターネットを通して、暗号化した通信で安全に AWS とつなぐサービス。Site-to-Site VPN と Client VPN がある。

  • AWS Site-to-Site VPN

    会社のネットワークと VPC を、インターネットを通る暗号化した通信でつなぐサービス。
