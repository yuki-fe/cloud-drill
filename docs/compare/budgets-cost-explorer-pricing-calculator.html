AWS Budgets と Cost Explorer と Pricing Calculator の違い

Pricing Calculator は使う前に料金を見積もる道具、Cost Explorer はこれまでの料金をグラフで分析する道具、AWS Budgets は予算を決めて超えそうなときに知らせるサービスです。

表で比べる

観点AWS Pricing CalculatorAWS Cost ExplorerAWS Budgets
使う時期AWS を使う前使ったあと使っている間（先回り）
すること構成を入力して、月の料金を見積もるこれまでの料金と使い方をグラフで見て分析する。この先の予測もできる予算を決め、使った額や予測が予算を超えそうなら知らせる
答えてくれる問いこの構成だといくらになりそうか何にいくら使ったか、なぜ増えたか予算を超えそうになったら教えてほしい

見分けるポイント

  • 「使う前に見積もる」「新しい構成の費用」なら Pricing Calculator
  • 「過去の料金を分析」「グラフ」「傾向を見る」なら Cost Explorer
  • 「予算」「しきい値を超えたら通知（アラート）」なら Budgets
  • いちばん細かい料金のデータを出すのは Cost and Usage Reports

試験での出され方

「毎月の費用が決めた額を超えそうになったら通知を受けたい」なら Budgets、「先月の費用が増えた原因をサービスごとに調べたい」なら Cost Explorer、のように、いつ・何をしたいかで選ぶ問題がよく出ます。

それぞれの用語

  • AWS Budgets

    予算を決めて、使った額や、この先の予測が予算を超えそうなときに知らせるサービス。

  • AWS Cost Explorer

    これまでの料金の使い方をグラフで見て分析し、この先の予測もできる道具。

  • AWS Pricing Calculator

    AWS を使う前に、構成を入力して月の料金を見積もる道具。
