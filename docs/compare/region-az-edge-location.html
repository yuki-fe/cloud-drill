リージョンとアベイラビリティーゾーンとエッジロケーションの違い

リージョンは世界の地域、アベイラビリティーゾーン（AZ）はリージョンの中にある独立したデータセンターの集まり、エッジロケーションは利用者の近くでデータを速く届けるための拠点です。

表で比べる

観点リージョンアベイラビリティーゾーン（AZ）エッジロケーション
何かデータセンターが集まっている世界の地域リージョンの中にある、独立したデータセンターの集まり利用者の近くに置かれた拠点
関係1つのリージョンに複数の AZ があるリージョンの中に複数あるリージョンとは別に、世界の多くの都市に置かれる
主な目的データを置く国・利用者への近さ・料金・使えるサービスで選ぶ複数の AZ に分けて置き、高可用性にするCloudFront などがキャッシュして、速く届ける
障害への備え別のリージョンに置くと、災害対策（DR）になるAZ どうしは電源やネットワークを分けていて、同時に止まりにくい-

見分けるポイント

  • 「データを置く国の法律」「データ主権」「料金や使えるサービスが違う」ならリージョン
  • 「高可用性」「1つのデータセンターが止まっても」「マルチ AZ」なら AZ
  • 「キャッシュ」「低い遅延で配信」「CloudFront」ならエッジロケーション
  • 大きさの順は、リージョン ＞ AZ ＞ データセンター

試験での出され方

「リージョンを選ぶときに考えることはどれか（2つ選べ）」や、「高可用性のために、EC2 を複数の何に分けて置くか」のような問題がよく出ます。リージョンの選び方は、法律（データ主権）・利用者への近さ・使えるサービス・料金の4つで覚えましょう。

それぞれの用語

  • リージョン

    AWS のデータセンターが集まっている、世界の地域。データを置く国の決まり・利用者への近さ・料金・使えるサービスで選ぶ。

  • アベイラビリティーゾーン（AZ）

    1つのリージョンの中にある、独立したデータセンターの集まり。電源やネットワークを別にしていて、同時に止まりにくい。複数の AZ に分けて置くと高可用性になる。

  • エッジロケーション

    利用者の近くに置かれた拠点。CloudFront などがデータを一時的に保存（キャッシュ）して、速く届けるのに使う。
