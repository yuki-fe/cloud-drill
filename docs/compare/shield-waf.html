AWS Shield と AWS WAF の違い

AWS Shield は大量の通信でサービスを止める DDoS 攻撃から守るサービス、AWS WAF は SQL インジェクションなど Web アプリをねらう攻撃を、決めたルールで止めるファイアウォールです。

表で比べる

観点AWS ShieldAWS WAFAWS Firewall Manager
守る攻撃DDoS 攻撃SQL インジェクション・クロスサイトスクリプティングなど、Web アプリへの攻撃（守るルールをまとめて管理する）
しくみStandard は追加料金なしで自動で守る。Advanced は有料で、より高度な保護と専門チームの支援決めたルール（IP アドレス・リクエストの中身など）で、通信を許可・ブロックする複数のアカウントの WAF や Shield などの設定を、まとめて当てる
設定Standard は設定しなくても有効利用者がルールを作る（用意されたルールも使える）AWS Organizations と組み合わせて使う
組み合わせる相手CloudFront・Route 53・ロードバランサーなどCloudFront・Application Load Balancer・API Gateway など-

見分けるポイント

  • 「DDoS」が出てきたら Shield。「追加料金なしで自動」なら Shield Standard
  • 「DDoS の専門チームの支援」「より高度な保護」なら Shield Advanced
  • 「SQL インジェクション」「クロスサイトスクリプティング」「特定の IP アドレスをブロック」なら WAF
  • 「複数のアカウントでまとめて管理」なら Firewall Manager

試験での出され方

「DDoS 攻撃から守るために、すべての利用者が追加料金なしで使えるものはどれか」（Shield Standard）や、「SQL インジェクションを防ぐには」（WAF）のような問題がよく出ます。

それぞれの用語

  • AWS Shield

    DDoS 攻撃からシステムを守るサービス。Standard は追加料金なしで自動で使え、Advanced は有料で、より高度な保護と専門チームの支援がある。

  • AWS WAF

    Web アプリへの攻撃（SQL インジェクションなど）を、ルールで見分けて止めるファイアウォール。CloudFront などと組み合わせて使う。

  • AWS Firewall Manager

    複数のアカウントの WAF や Shield などのルールを、まとめて設定・管理するサービス。
