分野別ミニテスト4分野から20問。分野ごとの正答率がわかる

ミニテストについて

  • 1回20問（クラウドの概念 5問・セキュリティとコンプライアンス 6問・テクノロジーとサービス 7問・請求・料金・サポート 2問）。試験ガイドの配点の割合に合わせています。
  • 説明文を読んで、当てはまる用語をA〜D から選びます。答えはすべて解き終わってから表示します。
  • 間違えた用語は、ホームの「復習」に入ります。

本番の試験は、分野ごとの合格点はなく、全体の点数（700点以上）で合否が決まります。とはいえ、配点の大きいセキュリティ（30%）とテクノロジー（34%）で点を落とすと届きにくくなるので、正答率の低い分野から復習しましょう。

このミニテストは用語の確認のためのもので、本番の問題の形や採点の方法とは異なります。
